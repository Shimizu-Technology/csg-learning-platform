Your local CRUD API is working. So far its routes have been unversioned to keep the first request/controller steps small. Now give the API a stable /api/v1 boundary before adding signup and sessions. Use the CSG API versioning guide.

Move the CRUD controllers you already have under app/controllers/api/v1 and change their class names to Api::V1::YourController. Wrap the existing routes in namespace :api and namespace :v1. Keep the resource/action names and allowed HTTP methods your API already supports. Do not create a second set of public routes just to keep old URLs working.

Run rails routes and verify the new paths. In HTTPie desktop retest index, show, create, update and destroy under http://localhost:3000/api/v1, one request at a time. Use Body → Form → URL-encoded rows for write data and Params for non-sensitive query values. Confirm the old unversioned routes return 404. Read the Rails log after each request, then update your README endpoint table.

Signup and session controllers do not exist yet on this path. Generate them directly under Api::V1 in the following password/signup/session lessons; do not try to test login before building it. This is the upgrade from the earlier deliberately small route setup.
