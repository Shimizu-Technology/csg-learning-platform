Deploy React to Netlify while keeping the API on the frontend's origin through a proxy rewrite. Use the final CSG Render and Netlify guide and the React session guide.

Set Netlify's build command to npm run build, publish directory to dist and VITE_API_BASE_URL to /api/v1. In public/_redirects put the API rewrite first, then the SPA fallback:

/api/* https://YOUR-API.onrender.com/api/:splat 200
/* /index.html 200

Replace YOUR-API with your service. Keep /api exactly once. API requests must reach Render, not return index.html. Follow the guide's first-party cookie settings: HTTP-only, SameSite=Lax and Secure in production. The cookie belongs to the public Netlify origin; do not set a Render-only cookie Domain. Do not use SameSite=None or rely on third-party cookies.

The shared client still calls /api/v1 through the frontend origin, with credentials and an in-memory CSRF header on writes. Do not point it directly at the Render hostname or solve proxy problems by disabling CSRF. In DevTools inspect request URL, status, response body and cookie flags. Keep secret cookie values out of evidence.
