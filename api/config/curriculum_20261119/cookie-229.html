Restore and protect the session with the CSG React session guide. Use the same api instance and CSRF helpers from signup/login.

On load, get /csrf and then /session. Render a loading state while checking. A valid session fills the shared user state; 401 leads to login; network failure shows a retryable unavailable state. Do not flash protected task screens while the check is pending.

Implement logout through writeRequest('delete', '/logout'). After success clear the shared user and in-memory CSRF token, then fetch a fresh CSRF token for the next login. The Rails response clears the HTTP-only cookie; JavaScript should not read or delete it.

Test a page reload, logout, expired/missing session, invalid CSRF on a write, an unavailable API and two-user isolation. Only then connect authenticated reads and CRUD in the following lessons. Use separate browser profiles or log out between users; never copy a cookie or token into source code.
