One client for this JWT course

The maintained CRUD guide now also supports cookie-session projects. Your course API uses Bearer JWT authentication from lessons 203–206. Keep that contract: do not add cookie/CSRF authentication halfway through this project. Use this one client for every React request, including the login form. The linked JWT reference matches this API; the cookie-session guide is a different backend contract.

Create src/lib/api.js:

import axios from "axios";

export const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
});

Set VITE_API_BASE_URL=http://localhost:3000/api/v1 in the ignored .env.local file and restart Vite. Import api from this module in every component and AuthContext, adjusting the relative path to the file. Call api.get("/tasks"), api.post("/login", values), and the other request methods on that same instance. Do not create a second Axios instance or mix these calls with global Axios defaults. If your API has only a PUT update route, add PATCH too, or use api.put consistently with the route you actually have.
