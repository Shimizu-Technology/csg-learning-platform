Which terminal am I in?

CSG supports Mac and Windows with WSL (Ubuntu). On Windows, open Ubuntu or choose Ubuntu (WSL) in VS Code's terminal menu. VS Code should show WSL: Ubuntu in the lower corner. A PowerShell prompt beginning with PS is still Windows, even if its folder starts with \\wsl.localhost.

From PowerShell, type wsl to enter Ubuntu. Then run uname -s and pwd. Ubuntu prints Linux and your projects should be under /home/your-name/CSG. Mac's Terminal prints Darwin and uses /Users/your-name/CSG. Do not install a second Windows copy of Node to fix a WSL terminal mix-up.

For JavaScript, check node -v and npm -v in that same terminal. If they are missing there, follow the CSG Node setup guide for Mac or WSL. Windows Chrome and the HTTPie desktop app can use localhost to reach your WSL servers.
