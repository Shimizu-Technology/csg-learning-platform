# What to Test — CSG Connect 1.0.0 (22)

Build 22 brings the class-recording workflow into the app, including hosted recordings that play without sending you to a browser.

Please focus on:

- As an instructor or admin, open **Learn → Class recordings**, add a YouTube, Vimeo, Loom, or direct-video link, and save it as a draft.
- Confirm a draft stays private, then publish it and verify a student in that cohort can see it.
- Open a supported hosted recording and confirm it plays inside CSG Connect. Use **Open original** to verify the fallback still works.
- Start a YouTube, Vimeo, or uploaded recording, leave the screen, return, and confirm playback resumes and progress agrees with the web app.
- Edit the recording title, description, date, and hosted URL; confirm the provider label updates when the URL changes.
- Ask for help from a recording and confirm the request points to the correct class replay.
- Upload a small recording and confirm uploaded and linked videos appear together in one clear library.
- Spot-check curriculum browsing and editing, Today, Messages, Updates, grading, student support, and account settings for regressions.
- Test both reliable Wi-Fi and a weaker mobile connection. Embedding-disabled videos should explain the problem and keep **Open original** available.

Please report the account role, device model, iOS version, recording host, exact action, and whether the issue also reproduces on web. Public App Review remains intentionally deferred until physical-device acceptance is complete.
