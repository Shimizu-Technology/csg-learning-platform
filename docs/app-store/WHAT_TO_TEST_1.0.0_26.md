# What to Test — CSG Connect 1.0.0 (26)

Confirm TestFlight shows build `1.0.0 (26)`. Use an authorized instructor or admin account and, where available, a student account. For a defect, record the device, iOS version, role, cohort, steps, and whether it also occurs on desktop. Keep private student content out of reports.

1. As staff, open **Today → Student access** and choose the production alumni cohort. Check that app sign-in and GitHub organization membership appear separately. Compare a known member and a pending invitation with GitHub. Pull to refresh and check the timestamp. If GitHub is unavailable, its status should say so and its filters should be disabled.
2. Search by name and email. Try the GitHub invited, GitHub joined, follow-up needed, and app sign-in pending filters. Switch cohorts and confirm the list and counts change without carrying status from the previous organization.
3. On a compact iPhone, open **Messages → New message**. The workspace strip should stay above search, the recipient list should scroll to its last entry, and the screen should open with the keyboard closed. Focus search, then dismiss the keyboard by scrolling, tapping **Done**, tapping the header, and selecting a recipient. Switching workspaces should clear the selected recipients.
4. Start a one-to-one message and a group message. Confirm the chosen recipients and composer are correct. Repeat as a student where authorized.
5. On desktop, check that the home-page “Progress saved automatically” badge sits below the illustration. Check a narrow browser width too. In the cohort **Students** tab, verify the separate app and GitHub states, search, filters, refresh, and unavailable state.

Complete the broader physical-device checklist in the [release record](README.md) before any public App Review submission.
