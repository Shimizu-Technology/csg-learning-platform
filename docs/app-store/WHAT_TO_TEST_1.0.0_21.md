# What to Test — CSG Connect 1.0.0 (21)

Build 21 adds the complete native curriculum-authoring workflow for instructors and admins.

Please focus on:

- Open **Learn**, search the curriculum library, and preview an existing lesson.
- Tap **Edit** and confirm the lesson title, required status, video, exercise, submission mode, code runner, objectives, rubric, and recall-check controls are clear and touch-friendly.
- Edit rich lesson instructions, including formatted text, links, lists, quotes, and code. Preview the device draft before saving, leave and return, and confirm the draft is preserved.
- Save a small test change and confirm the same lesson content appears on the web app. Restore the original content afterward.
- Create or reorder a test module/lesson where authorized, then archive it and confirm students never see draft or archived material.
- Upload or replace a test lesson video and verify progress remains tied to the canonical lesson.
- Spot-check Today, Messages, Updates, Recordings, grading, student support, and account settings for regressions.
- Test both reliable Wi-Fi and a weaker mobile connection. Confirm failed changes are explicit and never look saved.

Please report the account role, device model, iOS version, screen, exact action, and whether the issue also reproduces on web. Public App Review remains intentionally deferred until the physical-device acceptance checklist is complete.
