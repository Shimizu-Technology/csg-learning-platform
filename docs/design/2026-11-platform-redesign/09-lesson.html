A loop repeats a block of code. The for loop is the one you'll use most: it sets up a counter, checks a condition, and updates the counter after each pass.

JavaScript
for (let i = 1; i <= 5; i++) {
  console.log(`Count: ${i}`)
}
// Count: 1 … Count: 5

If the condition never becomes false, the loop never stops. That's the most common loop bug, so check your condition first when something hangs.
