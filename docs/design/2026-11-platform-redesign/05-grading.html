Write ticketPrice(age): children under 12 pay $5, seniors 65 and over pay $6, everyone else pays $10.

Answer

I used if / else if / else so only one price is returned. I checked the child case first because it's the smallest range.

ticket-price.js
function ticketPrice(age) {
  if (age < 12) {
    return 5
  } else if (age >= 65) {
    return 6
  } else {
    return 10
  }
}
