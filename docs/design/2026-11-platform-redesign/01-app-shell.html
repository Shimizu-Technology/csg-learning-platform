How defaults and overrides work

School settings set the default for every cohort. A cohort can override any switch in its Settings tab; the row shows "Overridden in 2 cohorts" with links. Defaults match what CSG runs today: help requests, office hours, recordings and updates on; class channels on for live programs; course community off.
