# P5 Updates correctness

2026-10-22; isolated branch `fix/p5-updates`. Agent-executed affected-flow QA; no simulator or production writes.

CSG Learn serves Code School of Guam students, who rely heavily on phones, and a small teaching team. Updates contains a contextual announcement feed and an account-wide notification Inbox. Readers need exact records, reliable read state, clear audience labels, older history, and a return to the same list. Staff announcement management retains exact audience/cohort/status filters.

Sources: audit WORKER_BRIEF.md and PLAN.md (2026-10-22), verify-comms.md section 5 (N-C3/4/5/6/8), repository AGENTS.md and PRODUCT_VISION.md, Announcement/Notification models and controllers, web Announcements/Layout, native Updates and messaging caches. Brain-Dump code-school/_overview.md supplies historical school context; the newer brief governs pilot decisions. API deploys on Render and web on Netlify. This PR is held for lead integration; no migration or production data repair.

Unread policy:

- Inbox total = unread delivered notifications across the account, including notices from muted conversations. Notification read state and conversation message-read cursors are distinct: dismissing a notification does not claim the conversation was read.
- Message attention badges = unread messages in unmuted conversations. Web sidebar, web workspace totals, native tab, and native workspace totals use this rule.
- Announcement unread = unread delivered announcement notifications within the requested visible audience/cohort scope, independent of pagination and read filter. Old readable announcements without a delivery record are history, with `unread: false`; they do not create phantom unread dots. Reader cohort context includes school-wide announcements. `audience=cohort` explicitly requests only that cohort; management filters remain exact.
- Reading a conversation invalidates native messaging and Updates caches. Reading announcement detail and notification mutations refresh web observers/sidebar and related native pages. Mark-all updates every cached announcement/notification page and invalidates all cohort scopes.
